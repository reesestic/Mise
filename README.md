# Mise project workspace

Mise is a proposed mobile app for Pantry-aware cooking and meal-informed grocery planning. This workspace currently contains product direction, screen specifications, system/design diagrams, and visual references. Application code has not been scaffolded yet.

## Project areas

- [Visual](Visual/README.md) — art direction, mood board, screen prototype, and app imagery.
- [Diagrams](Diagrams/README.md) — architecture, domain model, interactions, and repository map.
- [Project Roadmap](Project%20Roadmap/PROJECT_ROADMAP.md) — product guardrails, phases, and links to screen specs.
- [Structure](Structure/README.md) — proposed repository, domain model, and technology choices.
- [Misc](Misc/README.md) — materials that do not belong to a primary area yet.

## Recommended first implementation choice

Start with **Expo + React Native + TypeScript** for the mobile app and **Supabase/PostgreSQL** for accounts and connected data. See [TECH_STACK.md](Structure/TECH_STACK.md) for setup and third-party services. Use [the roadmap](Project%20Roadmap/PROJECT_ROADMAP.md) to work through the product in phases.
